How this prototype works

LINZ boundary first. Review second.

The map no longer relies on rough fake parcel boxes. Demo flats start with a coordinate, then Flatwise asks the official LINZ boundary layer which real property contains that point.

01

Load official property polygons

At close zoom levels, the map pulls LINZ NZ Property Boundaries as GeoJSON for the current view.

02

Click the exact boundary

The polygon itself is interactive. A background click also performs a direct LINZ point lookup.

03

Snap demo flats

Demo markers attach to the official property polygon under their seed coordinate instead of staying as loose map pins.

04

Store local reviews

Saved notes stay in localStorage for safe testing before any real backend is added.
