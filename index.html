How the MVP works

Built for GitHub Pages, designed like a real app.

01

Map selection

Leaflet loads OpenStreetMap tiles. When you click, Overpass checks for a nearby building.

02

Rent benchmark

The selected location is matched to the nearest local rent benchmark entry in data/rent-data.json.

03

Flat review

Users rate rent value, cleanliness, warmth, noise, safety, flatmate vibe, communication, pressure, and liveability.

04

Safe prototype storage

New reviews save in the browser using localStorage, so it works on static hosting with no backend.
